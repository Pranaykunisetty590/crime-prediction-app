System Requirements
===================

Hardware Requirements
---------------------

Processor: Intel Core i5 or equivalent

RAM: 8 GB

Storage: Minimum 500 MB free space

Display: Screen resolution 1280 x 720 or higher (for Streamlit dashboard)


Software Requirements
---------------------

Programming Language: Python 3.10 / 3.11 / 3.12

Web Framework: Streamlit 1.28 or higher

Database: MySQL (for future use); currently data is loaded from CSV files

Libraries Used:
  - pandas (data loading and preprocessing)
  - numpy (numerical operations)
  - matplotlib (plotting)
  - seaborn (statistical visualizations)
  - scikit-learn (train/test split, Random Forest, K-Means, metrics)
  - folium (interactive maps and heatmaps)
  - lightgbm (LightGBM classifier for crime type prediction)
  - prophet (optional; time-series forecasting)
  - import matplotlib.pyplot as plt

Operating System: Windows 10/11, macOS 10.14+, or Linux

Browser: Any modern web browser (Chrome, Firefox, Edge) for viewing the app
